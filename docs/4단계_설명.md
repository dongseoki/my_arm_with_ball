# MoveIt 적용 4단계 설명 — Gazebo 공 집기 시험

## 목적과 범위

4단계는 RG2 그리퍼가 공과 접촉하고, 닫힘 조건을 만족한 경우에만 공을 붙이는 동작을 구현한다. 공을 잠시 들어 올려 그리퍼를 따라오는지 확인한 뒤 분리하고, 낙하 및 MoveIt Planning Scene 반영까지 시험한다. 바구니로 옮겨 놓는 전체 Pick-and-Place 작업은 5단계 범위다.

## 실행 방법

프로젝트 루트에서 다음 명령으로 헤드리스 자동 시험을 실행한다.

```bash
source /opt/ros/jazzy/setup.bash
export GZ_VERSION=harmonic
colcon build --symlink-install
source install/setup.bash
ros2 launch my_arm_with_ball_bringup pick_grasp_test.launch.py headless:=true rviz:=false
```

성공하면 `STAGE4 GRASP TEST PASSED`가 출력되고 launch가 정상 종료 코드로 끝난다. 화면을 함께 확인하려면 `headless:=false rviz:=true`를 지정한다. 자동 시험은 공을 바구니로 운반하지 않는다.

## 검증 결과 및 경계

- 전체 워크스페이스 `colcon build --symlink-install`: 통과.
- `colcon test` 및 `colcon test-result --verbose`: 5개 테스트, 실패 0.
- 새 로직/Planning Scene 단위 테스트: 13개 통과. 새 Python 파일 lint와 변경 C++ 파일 정적 검사도 통과.
- 헤드리스 Gazebo + MoveIt 집기 통합 시험: 2회 통과. 빈손 부착 거부, 접촉·부착, 공 동반 상승, 분리·낙하 및 Planning Scene 위치 동기화를 확인했다.
- 일반 simulation 및 계획 전용 demo는 headless 실행으로 초기 Planning Scene 등록을 확인했다. RViz 화면에서의 수동 시각 검증은 수행하지 않았다.

이 시험은 시뮬레이션에서의 상태 전환과 소프트웨어 동기화를 검증한다. 실제 그리퍼의 파지력·마찰·미끄러짐 성능이나 실제 하드웨어 동작을 보증하지 않는다.
