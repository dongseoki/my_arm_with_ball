# `grasp_scene.py` 쉽게 이해하기

## 한 줄 요약

`my_arm_with_ball_application/scripts/grasp_scene.py`는 **MoveIt이 계획에 사용하는 장면(Planning Scene)에서 공 `apple`의 상태를 바꾸는 도구**입니다. 공을 로봇 손에 잡힌 것으로 기록하거나, 손에서 떨어져 월드에 놓인 것으로 되돌립니다.

> 중요한 구분: 여기서 말하는 부착/분리는 MoveIt의 충돌 장면 정보 변경입니다. Gazebo에서 공을 실제로 물리적으로 붙이고 떼는 동작은 별도의 `/grasp/attach`, `/grasp/detach` 서비스가 합니다. 한쪽만 실행한다고 다른 쪽 상태까지 저절로 바뀌지는 않습니다.

## `attach_ball()` — MoveIt에 “공을 손에 들었다”고 알리기

호출 형태는 `attach_ball(node, ball_pose_world, hand_pose_world)`입니다.

쉽게 비유하면, 탁자 위에 있던 공 모형을 치우고 로봇 손에 붙은 작은 모형으로 바꾸는 작업입니다.

1. 공의 월드 좌표와 손의 월드 좌표를 받아 **공이 손을 기준으로 어디에 있는지** 계산합니다. 그래야 손이 움직여도 MoveIt에서 공이 손에 붙어 따라갑니다.
2. 공의 충돌 모형을 반지름 `0.0325 m`인 구로 만들고, 부착 링크를 `rg2_hand`로 지정합니다. 손과 두 손가락(`rg2_leftfinger`, `rg2_rightfinger`)은 공에 닿을 수 있는 링크로 지정합니다.
3. MoveIt의 `apply_planning_scene`에 변경을 요청합니다. 같은 ID(`apple`)의 월드 공은 없어지고, 손에 부착된 공으로 기록됩니다.
4. `get_planning_scene`으로 결과를 다시 읽어 **월드에는 없고 `rg2_hand`에 붙어 있으며, 구의 모양과 위치도 맞는지** 확인합니다. 확인된 경우에만 `True`를 돌려줍니다.

좌표가 `world` 기준이 아니거나 위치/자세 값이 잘못된 경우, MoveIt 서비스가 거부되거나 제한 시간 안에 결과가 확인되지 않는 경우에는 예외가 발생합니다. 기본 제한 시간은 30초입니다.

## `detach_ball()` — MoveIt에 “공을 손에서 놓았다”고 알리기

호출 형태는 `detach_ball(node, ball_pose_world)`입니다. `ball_pose_world`는 분리 시점에 측정한 공의 현재 월드 자세입니다.

쉽게 비유하면, 손에 붙어 있던 공 모형을 떼어 내어 **측정된 위치에 다시 놓인 월드 공 모형**으로 바꾸는 작업입니다.

1. 손에 부착된 `apple`을 제거합니다.
2. 전달받은 월드 자세에 공 충돌 모형을 다시 추가합니다. 즉, 공을 놓은 위치를 MoveIt에 알려줍니다.
3. 한 번의 Planning Scene 변경 요청에 두 변경을 함께 담아, 손에 붙은 공을 제거하면서 월드 공을 복원합니다.
4. MoveIt에서 다시 조회해 **`rg2_hand`에는 붙어 있지 않고, 월드에는 공이 하나 있으며, 구의 모양과 위치가 전달한 측정값과 맞는지** 검증합니다. 확인되면 `True`를 반환합니다.

이 함수는 공을 Gazebo에서 실제로 떨어뜨리거나 물리적으로 움직이지 않습니다. 그런 동작은 Gazebo의 `/grasp/detach`가 하고, `detach_ball()`은 그 결과로 측정된 위치를 MoveIt 장면에 반영합니다. 기본 제한 시간은 30초이며, 서비스 실패·잘못된 자세·시간 초과 시 예외가 발생합니다.

## 테스트에서의 순서

`grasp_test.py`의 잡기/놓기 흐름은 두 시스템을 각각 갱신합니다.

| 시점 | Gazebo 물리 시뮬레이션 | MoveIt Planning Scene |
| --- | --- | --- |
| 공을 잡을 때 | `/grasp/attach`로 손과 공을 물리적으로 연결 | `attach_ball()`로 공을 손에 붙은 충돌 물체로 기록 |
| 공을 놓을 때 | `/grasp/detach`로 물리 연결을 풀어 공이 떨어지게 함 | `detach_ball()`로 부착 물체를 지우고 측정 위치에 월드 공을 복원 |

따라서 `attach_ball()`은 Gazebo의 attach 서비스를 대신하지 않고, `detach_ball()`도 Gazebo의 detach 서비스를 대신하지 않습니다. 둘은 MoveIt이 로봇 경로를 계획할 때 공과 로봇의 충돌을 올바르게 고려하도록 장면을 동기화하는 역할입니다.

## 파일 안의 다른 관련 기능

- `refresh_ball()`은 공이 떨어진 뒤의 새 측정 위치로 월드 공을 다시 갱신합니다. `detach_ball()` 이후 낙하가 진행된 경우 최종 위치를 반영하는 데 사용됩니다.
- `set_ball_touch_allowed()`는 공과 손/손가락 사이의 접촉을 허용하거나 되돌리는 충돌 행렬을 설정합니다. `attach_ball()`과는 별도의 기능입니다.
- 파일은 Planning Scene 서비스의 응답만 믿지 않고, 장면을 다시 조회해 객체 ID, 부착 링크, 구 형상과 위치까지 확인합니다.
