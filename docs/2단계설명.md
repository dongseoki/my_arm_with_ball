# MoveIt 2단계 변경 파일 설명

아래는 2단계에서 추가하거나 갱신한 파일과 각 파일의 역할이다.

## 패키지와 MoveIt 설정

- `my_arm_with_ball_moveit_config/package.xml` — MoveIt 설정 패키지의 메타데이터와 빌드·실행 의존성을 선언한다.
- `my_arm_with_ball_moveit_config/CMakeLists.txt` — `planning_scene_loader`와 계획 검증 스크립트를 빌드·설치한다.
- `my_arm_with_ball_moveit_config/.setup_assistant` — MoveIt Setup Assistant가 사용할 로봇 설명 패키지와 기본 설정 경로를 기록한다.
- `my_arm_with_ball_moveit_config/config/ur5_rg2.srdf` — UR5 계획 그룹, 기본 자세, 가상 조인트 및 검토된 충돌 제외 쌍을 정의한다.
- `my_arm_with_ball_moveit_config/config/kinematics.yaml` — UR5 역기구학 계산에 사용할 KDL 설정을 지정한다.
- `my_arm_with_ball_moveit_config/config/joint_limits.yaml` — 계획 시 적용할 조인트 속도·가속도 제한을 제공한다.
- `my_arm_with_ball_moveit_config/config/ompl_planning.yaml` — OMPL 계획 파이프라인과 UR5 기본 계획기를 설정한다.
- `my_arm_with_ball_moveit_config/config/moveit_controllers.yaml` — MoveIt의 컨트롤러 연결 설정 파일이다. 현재 데모에서는 궤적 실행이 비활성화되어 실제 로봇 제어에 사용되지 않는다.
- `my_arm_with_ball_moveit_config/config/moveit.rviz` — MoveIt MotionPlanning 패널과 로봇·장면 표시를 위한 RViz 설정이다.

## 실행 파일과 검증

- `my_arm_with_ball_moveit_config/launch/demo.launch.py` — 독립 계획 데모용 상태 발행기, MoveGroup, 계획 장면 로더 및 선택적 RViz를 실행한다.
- `my_arm_with_ball_moveit_config/launch/move_group.launch.py` — OMPL 기반 MoveGroup을 실행하며 궤적 실행 기능은 끈다.
- `my_arm_with_ball_moveit_config/launch/moveit_rviz.launch.py` — MoveIt 설정을 읽어 RViz와 MotionPlanning 패널만 실행한다.
- `my_arm_with_ball_moveit_config/src/planning_scene_loader.cpp` — 바구니와 사과를 MoveIt 계획 장면에 충돌 물체로 등록한다.
- `my_arm_with_ball_moveit_config/scripts/validate_planning.py` — 상태 유효성, IK, 충돌 회피 및 목표 간 경로 계획을 서비스로 검증한다.

## 메시와 기록

- `my_arm_with_ball_moveit_config/meshes/basket.stl` — MoveIt 계획 장면에서 바구니 충돌 형상으로 사용하는 메시다.
- `my_arm_with_ball_moveit_config/meshes/ATTRIBUTION.md` — 바구니 메시의 출처와 라이선스 표시를 기록한다.
- `plan/m_2_plan.md` — 2단계 설계 및 구현 결과, 검증 내용과 제약을 기록한다.
- `plan/moveit_apply.md` — 전체 MoveIt 적용 계획에서 2단계 완료 상태를 표시한다.

## RViz에서 시점을 움직일 수 없는 이유

`my_arm_with_ball_moveit_config/config/moveit.rviz`에는 RViz의 `Tools` 목록이 저장되어 있지 않다. 반면 시뮬레이션 설정인 `my_arm_with_ball_bringup/config/ur5_rg2.rviz`에는 `MoveCamera` 도구가 명시되어 있다. 따라서 MoveIt RViz 설정에 카메라 조작 도구가 빠져 툴바에서 선택할 수 없는 것이 우선 원인으로 보인다. 두 설정 모두 `Orbit` 뷰를 사용하므로 고정 프레임 차이는 시점 회전 불가의 원인으로 보이지 않는다.

## `demo.launch.py`를 별도로 만든 의도

`demo.launch.py`는 Gazebo나 ros2_control 없이 SRDF·OMPL·계획 장면과 경로 계획을 독립적으로 확인하기 위한 2단계용 진입점이다. 계획 과정이 기존 시뮬레이션 실행과 결합될 때 생길 수 있는 설정·실행 의존성을 분리하고, 궤적 실행도 비활성화해 구성 검증에 범위를 한정했다.

따라서 현재 구성은 사용자가 예상한 `simulation.launch.py` 통합과는 다르다. `simulation.launch.py`에 MoveIt 노드가 추가된 상태가 아니며, 두 환경 사이에 로봇 상태나 계획 장면도 자동 공유되지 않는다. 시뮬레이션에서 계획 결과를 실제 ros2_control로 실행하려면 실행 허용 설정, MoveIt 컨트롤러 연결, Gazebo 상태·장면 연동을 포함한 별도 통합 작업이 필요하다.
