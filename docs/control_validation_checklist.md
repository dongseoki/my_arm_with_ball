# Gazebo 제어 기준 확인 절차

이 문서는 Fixed Joint Waypoint 구현 전 0단계의 실행 검증 절차다. 현재 코드와 SDF를 수정하지 않고, Gazebo에서 수동 조작으로 `HOME`, 관절 방향, RG2 그리퍼 동작을 확인한다.

## 1. 실행

프로젝트 루트에서 다음 명령을 실행한다.

```bash
cd /home/dslee/workspace/my_arm_with_ball
source /opt/ros/$ROS_DISTRO/setup.bash
colcon build
source install/setup.bash
ros2 launch my_arm_with_ball_bringup simulation.launch.py keyboard:=true rviz:=false
```

`keyboard:=true`를 지정해야 키보드 입력 노드가 실행된다. 명령을 실행한 인터랙티브 터미널에서 아래 키를 입력한다.

| 키 | 동작 |
|---|---|
| `1`~`6` | 조정할 팔 관절 선택 |
| `a` | 선택한 관절을 `-0.05` rad 이동 |
| `d` | 선택한 관절을 `+0.05` rad 이동 |
| `o` | RG2 그리퍼 열기 |
| `c` | RG2 그리퍼 닫기 |
| `x` | 팔과 그리퍼를 초기 목표값으로 재설정 |
| `q` | 키보드 노드 종료 |

## 2. HOME 확인

시뮬레이션이 시작된 직후의 자세를 확인하고, `x`를 입력한 뒤 자세가 동일한지 확인한다.
 -> 초기 자세와 X가 동일하지는 않음.
확인할 내용:

- 로봇이 예상한 초기 자세에 있는가? -> O
- 팔 끝이 바닥이나 공에 충돌하지 않는가? -> O
- 이후 공 접근을 시작할 수 있는 자세인가? -> O

결과를 다음 형식으로 기록한다.

```text
HOME: 적절함 / 부적절함
문제: 없음 또는 구체적인 설명
```

## 3. 그리퍼 확인

다음 키를 차례로 입력한다.

```text
o
c
o
```

다음 내용을 확인한다.

- `o` 입력 시 두 손가락이 실제로 벌어지는가? -> O
- `c` 입력 시 두 손가락이 실제로 닫히는가? -> O
- 두 손가락이 서로 대칭으로 움직이는가? -> O
- 공을 손가락 사이에 넣을 수 있을 정도로 열리는가? -> 계산상으로는 가능.
- 닫았을 때 손가락이 공을 밀어내거나 관통하지 않는가? -> 모름

결과를 다음 형식으로 기록한다.

```text
그리퍼 o: 열림 / 안 열림
그리퍼 c: 닫힘 / 안 닫힘
손가락 대칭 동작: 정상 / 비정상
공을 손가락 사이에 넣을 공간: 있음 / 없음
그리퍼 관련 문제: 없음 또는 구체적인 설명
```

현재 프로젝트의 기준값은 다음과 같다.

| 동작 | 각 finger joint 목표값 |
|---|---:|
| 닫힘 | `0.0` |
| 열림 | `1.18` |

두 finger joint에는 같은 수치를 각각 발행한다.

## 4. 관절 방향 확인

각 관절을 하나씩 선택하고 `d`를 한 번 입력한 뒤 `a`를 입력하여 원래 값으로 되돌린다.

```text
1 -> d -> a
2 -> d -> a
3 -> d -> a
4 -> d -> a
5 -> d -> a
6 -> d -> a
```

관절 순서는 다음과 같다.

| 선택 번호 | Joint |
|---:|---|
| `1` | `shoulder_pan_joint` |
| `2` | `shoulder_lift_joint` |
| `3` | `elbow_joint` |
| `4` | `wrist_1_joint` |
| `5` | `wrist_2_joint` |
| `6` | `wrist_3_joint` |

정확한 로봇공학 용어가 필요하지 않다. 화면에서 보이는 방향을 일상적인 표현으로 기록한다.

```text
1번: d 입력 시 shoulder_pan_joint가 적절히 회전
2번: d 입력 시 shoulder_lift_joint가 적절히 회전
3번: d 입력 시 elbow_joint 가 적절히 회전
4번: d 입력 시 wrist_1_joint  가 적절히 회전
5번: d 입력 시 wrist_2_joint 가 적절히 회전
6번: d 입력 시 wrist_3_joint 가 적절히 회전
```

예시는 다음과 같다.

```text
2번: d 입력 시 팔이 위로 이동
3번: d 입력 시 팔꿈치가 안쪽으로 이동
```

## 5. 공과 바구니 위치 확인

초기 자세에서 공과 그리퍼의 상대 위치를 확인한다.

확인할 내용:

- 공이 로봇 기준으로 왼쪽/오른쪽/앞/뒤 어느 쪽에 있는가? -> 로봇을 정면에서 봤을때 왼쪽
- 공 위쪽으로 접근할 공간이 있는가? -> 있음.
- 공에 접근할 때 바닥 또는 로봇 링크와 충돌할 가능성이 있는가? -> 없음.
- 바구니는 공 위치에 비해 어느 방향에 있는가? -> 그건 너가 좌표로 직접 확인 할것. 
- 바구니 입구와 내부에 그리퍼가 접근할 공간이 있는가? -> 직접 로봇팔로 움직여봐야 알것 같다.

결과를 다음 형식으로 기록한다.

```text
공의 로봇 기준 위치: ____________________
공 위쪽 접근 공간: 있음 / 없음
공 접근 시 예상 충돌: 없음 / 있음
바구니의 로봇 기준 위치: ____________________
바구니 접근 공간: 충분함 / 부족함
```

현재 SDF에 기록된 기준 pose는 다음과 같다.

```text
공:     (0.55, -0.25, 0.0325)
바구니: (0.75,  0.25, 0.000022)
```

이 좌표는 모델 기준점이며, 실제 공 중심과 바구니 내부 위치는 Gazebo 화면에서 확인한 값을 우선한다.

## 6. 이번 단계의 완료 조건

다음 항목을 확인하면 0단계의 실행 검증이 끝난다.

- HOME 자세가 확인되었다.
- `o`와 `c`의 그리퍼 방향이 확인되었다.
- 공을 손가락 사이에 넣을 수 있는지 확인되었다.
- 6개 관절의 `d` 방향이 기록되었다.
- 공과 바구니의 대략적인 상대 위치가 기록되었다.
- 충돌 위험 또는 이상 동작이 기록되었다.
